Oops! Stickman

Draw quick shields, bridges, and barriers to save an unlucky stickman from absurd physics hazards.

About The Game

Oops! Stickman is a single-player offline drawing puzzle game built with SpriteKit and Objective-C. Each level gives you a stickman, a hazard, and a moment to sketch a clever solution before the chaos begins.

The game is designed for landscape play, quick retries, readable physics, and funny failure moments.

Features

  • Physics-based drawing puzzles
  • One-finger sketch controls
  • 50 handcrafted-style generated levels
  • Local progress and star ratings
  • Clean paper-doodle visual style
  • Fully playable offline

Can You Save Him?

Block falling rocks, redirect flying slippers, bridge dangerous gaps, and keep the stickman alive long enough to win. A tiny line can become the perfect shield, but one bad angle can lead to a very dramatic OOPS!
